# Fauzan Portfolio

Personal portfolio at [prayersrain.cloud](https://prayersrain.cloud). Next.js App Router, statically exported (`output: "export"`).

## Commands

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static site in out/
npm run lint
```

## Content

- Projects: `src/data/projects.ts` (also drives `/projects/[id]` and the sitemap)
- Career timeline: `src/data/journey.ts`
- Project images: `public/projects/`
